マンダラチャート(公開用・空のチャート) Ver.4.4
==========================================
このフォルダーは、アプリとしてネットに公開するためのものです(中身は空のチャートだけ。個人のデータは入っていません)。

■ 構成
  index.html … アプリ本体  / manifest.webmanifest … アプリの名前・アイコンの設定
  sw.js … オフラインでも開けるようにする仕組み  / icons/ … ホーム画面のアイコン(曼荼羅チャート)  / data/chart-blank.js … 空のチャート

■ 公開のしかた(GitHub Pages)
  1. GitHubで新しいリポジトリを作る(例: mandala-chart)。公開(Public)にする。
  2. このフォルダーの中身(index.html、manifest.webmanifest、sw.js、icons、data)を、そのままアップロードする(フォルダーごと入れず、中身をリポジトリの一番上に置く)。
  3. リポジトリの Settings → Pages → 「Deploy from a branch」→ Branch を main / (root) にして Save。
  4. 数分後に、https://(ユーザー名).github.io/(リポジトリ名)/ で開けるようになります。そのアドレスをスマホ・iPad・パソコンで開きます。

■ ホーム画面に置く(アイコン「まんだら」)
  ・iPhone / iPad(Safari): 共有ボタン →「ホーム画面に追加」
  ・Android(Chrome): メニュー →「アプリをインストール」(または「ホーム画面に追加」)
  ・パソコン(Chrome / Edge): アドレス欄の右の「インストール」アイコン
  ・インストールしたあとは、ホーム画面のアイコンから開いてください。保存データは、ブラウザで開いたときとアイコンから開いたときで別々になることがあります(特にiPhone)。アイコンから開いたあとに、JSONを読み込んでください。

■ 自分のチャートを入れる
  ・パソコンの自分用で「バックアップ ▾」→「書き出し(JSON)」。そのファイルをメールやクラウドで端末に送る。
  ・端末のアプリで「バックアップ ▾」→「読み込み(JSON)」でそのファイルを選ぶ。中身は、その端末の中にだけ残ります(ネット上には載りません)。
  ・パソコンと端末は自動では同期しません。どちらかで変えたら、書き出して、もう片方で読み込み直します。
  ・ブラウザやアプリのデータは、使わない期間が長いと消えることがあります。ときどきJSONを書き出して、控えを取ってください。

■ 更新するとき
  ・index.html などを差し替えてアップロードし直し、sw.js の中の CACHE の名前(mandala-app-v4.4)の数字を変えると、確実に新しい版に切り替わります。

■ Ver.4.4の変更点
  ・JSONの書き出しは、日付なしの固定名「チャート名.json」で上書き保存(ファイルが増えない)。iPhone/iPadは共有シートから「ファイルに保存」→「置き換える」。
  ・Chrome/Edgeでは、保存先のファイルが別の端末でもっと新しく書き出されていたら、上書き前に確認する
  ※以下は4.3の変更点
  ・画面の上の帯(全体に戻る・チャート名など)の上に余白を足し、字が上の縁にくっつかないようにした
  ※以下は4.2の変更点
  ・書き出し・バックアップのファイル名を「月.日.年 チャート名」に変更(チャート名が空ならゴールの名前)。テーマごとは、そのあとにテーマの名前が付く
  ※以下は4.1の変更点
  ・下の色の説明(未評価・使わない・段階1〜5)が、81マスの下の行に重ならないよう、チャートの下に場所を取る形に変更
  ※以下は4.0の変更点
  ・ホーム画面のアイコンから開いたとき、画面の上(時計・電池のバー)のもやを解消(バーを濃い色にし、上の余白を確保)
  ※以下は3.9の変更点
  ・ゴールをタップしたとき、最初にゴール名の欄に入力できる
  ・「使わない設定」中の説明文を分かりやすく変更
  ※以下は3.8の変更点
  ・何も書いていない項目には「評価」ボタンを出さない(文字を消すと評価は計算に入らない)
  ・項目をタップしたとき、最初にタイトル欄に入力できる(メモは下の欄をタップ)
  ・使い方に「目標は5つでも使える(×で外す)」を追記(日本語/English)

■ 使い方
  アプリの右上の「使い方」ボタンに、文章と動くデモがあります。日本語 / English の切り替えもあります。
